# CityHarvest Farm Consulting

Urban farming consulting — we design, build and manage productive urban farms on rooftops, vacant lots and underused land.

## Stack

- Next.js 16 (App Router, TypeScript strict)
- Tailwind CSS v4 + glassmorphism design system
- shadcn/ui components (radix-ui), framer-motion, embla carousels
- react-hook-form + zod v4 forms, sonner toasts

## Services

Rooftop Farm Design & Build · Community Garden Planning · Greenhouse & High-Tunnel Installation · Hydroponic & Aquaponic Consulting · Soil Health & Compost Programs · Farm-to-Table Partnerships · Urban Farm Operations & Management

## Development

```bash
npm install
npm run dev      # local dev
npm run build    # production build
npx eslint src   # lint
```
